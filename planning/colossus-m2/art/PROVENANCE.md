# Colossus art-study provenance and limits

Original images generated with the image-generation capability already supplied in this session, within the explicitly authorized concept/prototype-art assessment. No new service/account/API key, asset purchase or paid external API was arranged. No production-rights/creative-acceptance claim. Originals are preserved byte-for-byte here, independently of transient generated-image paths.

`colossus-concept.png`: original natural brown gorilla, elevated front-quarter camera, no armor/glow/weapon. The source PNG is1254×1254 RGBA; transparency is real, though very low-alpha fringe exists outside the main silhouette and needs final edge review. `colossus-editable.svg` references that raster as an editable underpainting, with independent paint-over and ground-registration groups. This is **mixed raster/vector composition**, not a fully vector anatomy drawing or an already separated limb rig. `build_composition.py OUTPUT.svg` embeds the original bytes for a self-contained export. Merely wrapping a raster does not prove animation editability; that remains an asset gate.

`pose-concepts.png`: second original generation referencing only the newly generated master. Six forms, top row idle/airborne/landing; bottom hit/Fatigued/Wounded. RGBA1536×1024; transparent gutters were checked. The dark brown visible in the conversation preview must not be mistaken for an opaque image background without inspecting alpha. The sheet has **unregistered scale/anchors, pose-view drift and unverified edge cleanup**. Its cell previews are explicitly studies, not production sprites or interpolatable frames. No runtime assets are exported from this sheet.

The owner's `Collossus_01.jpeg`/`Collossus_02.jpeg` inline sheets were visually available. KONG-01 informs natural identity; KONG-07/08 inform elevated camera/ground staging only. No original reference JPEG bytes were read from a Mac/workspace path, copied, cropped or used as runtime pixels. No uploaded-concept background, armor, attached growth, snow or mutation identity is bundled. The new candidates are not proprietary character copies, but automated generation does not establish final originality/licensing clearance by itself.

The initial hand-authored vector study under `rejected-vector/` is retained as a **rejected method**: consistent paths alone gave a front-biased flat icon unlike Guardian's dimensional miniature. It is not presented as a successful visual target or a reason to lower the requested quality. Production should retain the better elevated master direction, refine it at phone scale, author genuine views/poses and validate ground/contact proxies before integration.

Generation direction: original full-body natural dark-brown giant gorilla; camera looks downward about60° from horizontal in three-quarter perspective, broad top shoulder/crown planes while preserving face/chest/arms/knuckles/feet; stylized hand-painted military miniature shading, simplified large forms rather than photofur; serious expressive face; transparent isolated silhouette. The second generation requested only six coherent pose concepts, not an animation set. Generation is nondeterministic; original output bytes and hashes, not a promise of byte-identical regeneration, establish recovery.
